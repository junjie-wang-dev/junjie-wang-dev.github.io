# Social link logos

Brand SVG geometry is vendored from the official [Simple Icons repository](https://github.com/simple-icons/simple-icons), under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). The standalone SVGs add a monochrome fill; no CDN, font, script, or external SVG reference is used. Brand names and trademarks belong to their respective owners.

The email envelope and website globe are original simple outline drawings for this editor.
